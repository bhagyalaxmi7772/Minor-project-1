# WhatsApp Group DNA Analyzer

## 📌 Project Overview
This project analyzes a WhatsApp group chat using Python and NumPy. It extracts messages from an exported WhatsApp chat file and generates meaningful insights about participant activity and communication patterns.

## 🚀 Features
- Parse WhatsApp chat data
- Group overview statistics
- Messages per participant
- Most active participant
- Busiest day analysis
- Busiest hour analysis
- Top 10 most used words
- Activity heatmap using NumPy
- Average response time analysis
- Longest silent streak detection
- Personality archetypes
- Final analysis report

## 🛠️ Technologies Used
- Python
- NumPy
- Google Colab
- Jupyter Notebook

## 📂 Project Files
- `GroupDNA.ipynb` – Main project notebook
- `DADS Minor PROJECT dataset.txt` – WhatsApp chat dataset
- `README.md` – Project documentation

## ▶️ How to Run
1. Open `GroupDNA.ipynb` in Google Colab or Jupyter Notebook.
2. Upload the dataset file when prompted.
3. Run all cells from top to bottom.
4. View the generated WhatsApp Group Analysis Report.
